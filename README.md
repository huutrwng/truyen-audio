# Tu Tiên Audio Server 🎧
Server phát truyện audio Tu Tiên: Khai Cục Từ Dược Đồng Bắt Đầu.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/huutrwng/truyen-audio)

## Tính năng nổi bật
- Giọng đọc Nữ Hoài My Neural (Microsoft Edge-TTS).
- Tự động lưu tiến trình nghe mỗi 15 phút và khôi phục vị trí đang nghe dở khi mở lại web.
- Tùy chỉnh tốc độ đọc 1.0x -> 2.5x, hẹn giờ tắt, tự động chuyển chương.
- Giao diện thân thiện tối ưu cho màn hình điện thoại (PWA).

## Triển khai Cloud miễn phí (Render.com)
Bấm vào nút **Deploy to Render** ở trên, hoặc:
1. Đăng nhập vào [Render.com](https://render.com) bằng tài khoản GitHub.
2. Bấm **New** -> **Web Service**.
3. Chọn repository `huutrwng/truyen-audio`.
4. Bấm **Deploy Web Service**.
