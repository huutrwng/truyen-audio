# Tu Tiên Audio Server
Server phát truyện audio Tu Tiên: Khai Cục Từ Dược Đồng Bắt Đầu.
- Đầy đủ tính năng nghe audio giọng nữ Hoài My Neural.
- Tự động lưu tiến trình nghe mỗi 15 phút và khôi phục chính xác khi mở lại web.
- Hỗ trợ phát liên tục, hẹn giờ, điều chỉnh tốc độ từ điện thoại.
